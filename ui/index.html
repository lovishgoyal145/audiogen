Upstash Redis REST coordination is required to connect to your profile's Kaggle worker.

What this is used for:
AudioGen uses Upstash Redis REST coordination to discover the remote Kaggle worker tunnel URL, maintain session heartbeats, and coordinate profile audio generation jobs.
How to find or generate credentials:
  1. Go to console.upstash.com and sign in.
  2. Create a new Redis database (or select an existing one).
  3. In the database details, scroll to the REST API section.
  4. Copy and paste the UPSTASH_REDIS_REST_URL and UPSTASH_REDIS_REST_TOKEN below.
